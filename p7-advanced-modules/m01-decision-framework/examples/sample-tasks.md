# Sample Tasks

## Task 1
Description:
Rename and organize downloaded invoices from a shared Downloads folder into per-vendor subfolders based on the vendor name printed on each PDF.

Why it might be automated:
It's repetitive, low-judgment, and happens weekly. A new hire could do this from a one-line checklist: read vendor name, move file to matching folder.

Expected recommendation: rules

## Task 2
Description:
Review inbound support emails and route them to the right team (billing, technical, sales).

Why it might be automated:
High volume, but routing requires reading intent, not just keyword matching. The output (which team got it) is checkable against known categories, and misroutes can be corrected with a human fallback.

Expected recommendation: ai_automation

## Task 3
Description:
Decide whether a messy, undocumented internal approval process (who approves what, in what order, with no written rule) is ready for automation.

Why it might be automated:
It's tempting because it's manual and annoying, but nobody can currently describe the actual rules consistently, and there's no way to check whether a given approval outcome was "correct."

Expected recommendation: dont_automate_yet
